# P2Pro — памятка для Claude

Этот файл читает каждая новая сессия Claude. Здесь — как устроен проект и правила работы с владельцем.
Репозиторий публичный: сюда только техническое, без секретов и деловой переписки.

## Владелец
- Пишет по-русски, не программист, работает с телефона. Отвечать по-русски, просто и коротко, без кода в ответах.
- Пушить сразу в `main` (отдельные ветки и PR не нужны, если не попросит).
- Если сказал «пока ничего не делай в коде» / «пока не надо трогать» — код не менять.
- Перед публикацией в канал/рассылкой — тексты показывать ему, сам решает.
- Посты: профессионально и коротко, без лишнего.

## Безопасность (строго)
- Токен бота, service_role ключ Supabase, пароль БД, ключи Platega / xRocket / Bybit / Fraudex — **никогда** не просить в чат и не коммитить. Они только в Supabase Secrets.
- Supabase access token — только в GitHub secret `SUPABASE_ACCESS_TOKEN`.
- В коде можно: URL Supabase и publishable key (`sb_publishable_…`).
- Не коммитить файлы с cron-секретом и личные сделки.

## Что где
- Сайт https://p2pro.app — GitHub Pages из этого репо (`CNAME`).
- `index.html` — приложение (PWA, один файл): калькулятор, история, аналитика, связки, контрагенты, чёрный список, PRO, валюты RUB/KZT/UAH/BYN/EUR/USD.
- `admin.html` — веб-админка владельца (вход по одноразовому коду из бота `/admin` → «Веб-админка»; посторонним 404). Её же открывает iOS-приложение «P2Pro Админ» (`ios-admin/`, метка `P2ProAdmin` в user agent).
- `ios-app/` — iOS-обёртка приложения. `tariffs.html`, `legal.html`, `paid.html` — тарифы, политика, оплата.
- `supabase/*.sql` — миграции по порядку (выполняются вручную в SQL Editor Supabase).
- `supabase/functions/telegram-bot/index.ts` — бот @P2ProAppBot + API админки (`{admin_api, access_token}`) + API чёрного списка + cron.
- `supabase/functions/telegram-auth/` — вход через Telegram и оплаты.
- Supabase проект: `liddntvlxlupwfhpuwnp`.

## Деплой
- Любой push, затрагивающий `supabase/functions/**`, сам деплоит обе функции (`.github/workflows/deploy-functions.yml`). Проверять: `gh run list`.
- Сайт обновляется сам после push (pages build).
- SQL-миграции владелец запускает сам — дать ему готовый текст и куда вставить.

## Бот — ключевое
- `bot_state` — key-value (stGet/stSet/stTake), value NOT NULL jsonb.
- Владелец: `ADMIN_ID`. Меню `/admin`: рассылки, канал (автопосты, курс в канал), утренний отчёт, отложенные, сторож (watchdog), промокоды, партнёры, приветствие и кнопки (премиум-эмодзи), напоминание ушедшим (с одобрением владельца).
- Инлайн-режим (карточка сделки/треугольника в любом чате) — только для вошедших подписчиков канала.
- Партнёрская программа: кабинет партнёра в боте, уведомления о продажах, отключение уведомлений.
- Пробный PRO 7 дней.

## Проверка перед коммитом
- Бот: `npx tsc` / проверка типов `index.ts`; для логики — мини-тесты с замоканным Supabase.
- Страницы: Playwright (Chromium предустановлен, `require('playwright')`), локально `python3 -m http.server`, смотреть ошибки консоли и скриншоты на ширине 390 и 1280.
