# P2Pro

![P2Pro](icons/icon-192.png)

Калькулятор и дневник P2P-сделок: чистая прибыль с учётом комиссий, режимы «Сделка», «Круг» и «Треугольник», история, аналитика по биржам и банкам, подбор курса, связки между биржами и книжка контрагентов.

Сайт: https://p2pro.app/
